# 데이터와 로직의 공간적 분리 및 self 참조 방향 규명

인스턴스는 오직 자신의 상태(인스턴스 속성)만 들고 있는 순수 데이터 보관소이며, 클래스는 인스턴스들이 공유하는 함수(바이트코드)를 보관하는 공용 공구함으로 메모리상에서 완전히 분리되어 있음을 정립했다. 초기에 의심했던 '인스턴스/self가 클래스 함수를 포인팅한다'는 가설을 기각하고, self는 클래스의 공용 함수가 호출될 때 대상 인스턴스를 전달받는 첫 번째 매개변수 포인터(함수 -> 인스턴스 방향)임을 명확히 바로잡았다.

## Evidence
- '인스턴스 입장에서 self는 클래스에서 정의한 함수 객체를 참조하는가?'라는 질문에 대한 교정을 거쳐, 데이터와 로직의 분리 및 self is my_dog 참(True) 증명을 통해 올바른 참조 방향을 습득함.

## Implications
- 인스턴스 생성 시마다 메서드가 중복 복제되지 않는 이유와 my_dog.bark()가 Dog.bark(my_dog)와 동치인 이유를 시스템 레벨에서 자명하게 설명할 수 있음.
