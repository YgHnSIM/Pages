# CPython 객체 메모리 구조와 이름표 바인딩 멘탈 모델 확립

파이썬의 모든 값은 C 구조체 PyObject(식별자, 타입 포인터, 참조 카운터 헤더 + 페이로드) 형태로 힙(Heap)에 할당된 독립 객체이며, 변수는 메모리 주소를 가리키는 이름표(Label)에 불과함을 확인했다. 64비트 CPython 기준 정수 10000조차 28바이트의 PyLongObject 구조체로 존재하며, 이는 C 언어 표준 추상기계가 말하는 바이트 저장 영역(스택 변수 포함)과 질적으로 다른 풍부한 런타임 메타데이터 객체임을 확립했다.

## Evidence
- 세션 질의응답을 통해 C 언어 구조체 및 포인터 지식을 바탕으로 x = 10의 바인딩 동작과 C 추상기계 객체와의 차이점을 정확히 규명함.

## Implications
- 변수를 '상자'로 취급하여 발생하는 모든 초보적 오개념을 배제하고, 향후 불변/가변 객체의 재할당 및 인플레이스 수정 동작을 순수 포인터 관점에서 전개 가능.
